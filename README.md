📄 README.md: 3D 우주 비행사 점프 게임 (Extreme Jump Game)
🚀 프로젝트 소개
3D 우주 비행사 점프 게임은 Three.js와 Cannon.js 물리 엔진을 결합하여 구현한 웹 기반의 초고난도 수직 점프 챌린지 게임입니다. 플레이어는 중력을 거스르며 좁고 움직이는 플랫폼을 밟고 올라가 최종 목표인 154m 높이에 도달해야 합니다.

✨ 주요 특징
극한의 난이도: 플레이어 점프력에 최적화된 간격(3.0m)과 좁은 플랫폼.

동적 환경: 상하로 움직이는(Oscillating) 플랫폼과 최종 승리 지점.

특수 기능: 디버깅 및 재미를 위한 Fly Mode (P 키 토글).

애니메이션: 이동 및 Wave 액션(F 키)에 따른 자연스러운 애니메이션 전환.

분류,기술,역할
3D 렌더링,Three.js,"모든 시각적 요소(장면, 모델, 조명, 카메라) 렌더링."
물리 엔진,Cannon.js,"현실적인 중력, 충돌 감지 및 물리 시뮬레이션."
핵심 파일,JavaScript (ES Modules),게임 로직 및 플레이어 제어.

키,기능,모드,설명
"W, A, D",수평 이동,일반/비행,캐릭터 이동
Spacebar,점프 / 상승,일반/비행,"일반: 지면 점프, 비행: 수직 상승"
S,후진 / 하강,일반/비행,"일반: 뒤로 이동, 비행: 수직 하강"
P,Fly Mode 토글,전체,중력 및 속도 제어 모드 전환
F,Wave 액션,전체,손 흔들기 애니메이션 재생
"Q, E",카메라 회전,전체,플레이어 시점 회전
